# Optional deep-learning model weights

The default PoC uses classical POS/CHROM rPPG and **does not require any model weights**.

If a later phase adds PhysNet / PhysFormer / EfficientPhys / PhysMamba, place explicitly licensed checkpoint files here and load them through a dedicated adapter. Do not assume that a paper repository's checkpoint license is suitable for commercial deployment; review both code and weight licenses first.
